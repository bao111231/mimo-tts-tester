说明
· 本页为纯静态页面，所有请求直接从你的浏览器发往目标接口，不经过任何中转服务器。
· API Key 仅写入本机浏览器 localStorage，清除浏览器数据或点击“清除配置”即可移除。
· MiMo 调用规则：合成文本放在 assistant 消息（发声），提示词/风格指令放在 user 消息（不发声）；文本开头可加 (开心)(东北话) 等风格标签，任意位置可加 [笑][叹气] 等细粒度标签，(唱歌) 开头可触发演唱。
· 预置音色：冰糖 / 茉莉 / 苏打 / 白桦（中文），Mia / Chloe / Milo / Dean（英文）。
· MiMo 目前限时免费，限速约 100 次/分钟，以官方页面为准。
